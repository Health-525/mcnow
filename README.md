# 麦上吃 · McNow 🍔

> **不想选？麦上吃。**
> 基于麦当劳 MCP 的 AI 点餐决策引擎 —— 专为「不知道吃什么」的人设计。

[![McDonald's MCP](https://img.shields.io/badge/McDonald's-MCP-red)](https://github.com/M-China/mcd-mcp-server)
[![WorkBuddy](https://img.shields.io/badge/Built%20with-WorkBuddy-blue)](https://www.workbuddy.cn)

## 为什么做这个？

打开美团或麦当劳 App：一屏几十个套餐，翻十分钟，关掉，问自己"到底吃什么"——还是不知道。

**选择困难才是点餐的主场景。** 麦上吃不做第 101 个"套餐推荐助手"，而是把决策做到底：

```
🧠 不知道吃什么
   ↓
🗣️ 「不知道吃啥，看着办」
   ↓
🤖 最多问 2 个问题（或者直接拍板）
   ↓
🍔 一个方案 + 一句人话理由 + 真实价格（含优惠）
   ↓
✅ 「确认」→ 下单
```

**核心设计原则：宁可武断，不给选项。** 给 5 个推荐让用户继续选，只是把 App 的决策瘫痪搬进对话里。

## 两大核心能力

### 1. 决策引擎（核心）- **档位 A · 有想法**：「想吃辣的炸鸡，配个喝的，25 以内」→ 意图匹配组餐
- **档位 B · 大脑空白**：「看着办」→ 时段感知 + 预算习惯 → 直接拍板
- **套餐优先策略**：系统组餐永远先扫套餐（三件套/四件套/随心配 1+1），套餐价低于单品拼配价时绝不拆单买
- **时段感知**：离门店打烊还有 16 分钟？推 15 分钟能取走的宵夜方案
- **理由感**：每个推荐附带一句"为什么是它"——决策 + 说服一步到位

### 2. 新品雷达
实时读取菜单「上新」标签，一句话播报当前门店的新品——App 大菜单里混在一百个 SKU 里的新品，到这里就是主角。

## 快速开始

> 前置条件：申请麦当劳 MCP Token（[指南](https://github.com/M-China/mcd-mcp-server)）

### 在 WorkBuddy 中使用

1. 打开 WorkBuddy → 【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置MCP】
2. 填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

3. 启用 mcd-mcp 连接器，然后安装本 Skill（`skill/` 目录），对它说：

```
「不知道吃啥，25 块以内，看着办」
「想吃炸鸡，配点喝的」
「最近上什么新品了？」
```
