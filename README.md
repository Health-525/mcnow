# 麦上吃 · McNow

**不想选？麦上吃。**

一个跑在 WorkBuddy 里的麦当劳点餐决策引擎。你只需要说人话，它负责决定、算钱、下单、出付款码。

> 基于麦当劳官方 [mcd-mcp](https://github.com/M-China/mcd-mcp-server) ｜ 全程使用 [WorkBuddy](https://www.workbuddy.cn) 开发 ｜ 麦当劳程序员节创意开发大赛参赛作品

## 先看一段真实对话

以下是本项目开发当天，作者在麦当劳 MCP 上**真实发生**的一次点餐（22:51，未删减）：

> **人**：我不知道吃什么
>
> **麦上吃**：好，拍板模式。先说个要紧的——亚青村店 23:00 打烊，只剩 9 分钟，来不及了。旁边地铁站店 24 小时营业，切过去。
>
> （拉取门店菜单，扫描套餐池后）
>
> **麦上吃**：决定了，就它，不用再想：
>
> | | 商品 | 价格 |
> |---|---|---|
> | 🍗 | 蘸酱炸鸡（韩式芝士风味酱·上新） | ¥11.9 |
> | 🥤 | 茉莉奶绿雪冰 | ¥9.9 |
> | 🥠 | 黑洋酥小圆子风味派（本周新品） | ¥5.0 |
> | | **合计** | **¥26.8** ~~¥44.9~~ **省 ¥18.1** |
>
> **为什么是它**：亚青村店快打烊了，这家 24 小时；炸鸡是你今晚自己点过名的；顺手把本周刚上的 ¥5 派塞给你当夜宵彩蛋。套餐池我扫过了——唯一贴 craving 的麦辣鸡翅套餐 ¥36.5，比这套贵 ¥9.7，Pass。
>
> **就它吗？** 确认就下单，堂食外带说一声。

从"我不知道吃什么"到一张能扫的付款码，中间没有一次"请选择您想要的套餐"。

## 它解决什么问题

打开外卖 App 点麦当劳的真实流程：翻菜单十分钟 → 每个套餐都要心算价格 → 关掉 App → 问朋友"吃什么" → 还是不知道。

问题从来不是"没有好吃的"，是**决策成本被转嫁给了饿着肚子的你**。

麦上吃的设计只有一条主线：把决策成本降到底。

| 传统点餐 | 麦上吃 |
|---|---|
| 上百个 SKU 自己翻 | 说一句话，甚至不用说 |
| 套餐划不划算自己算 | 套餐优先 + 双向验价，只报低价方案 |
| 推荐列表永远有 5 个选项 | **只给 1 个方案，附一句真实理由** |
| 新品混在菜单第 4 屏 | 「上新」标签直达，一句话播报 |

## 三条核心设计

**1. 宁可武断，不给选项**
最多问 2 个问题，最终只给 1 个方案。给 5 个推荐让用户继续选，只是把 App 的决策瘫痪搬进对话里。

**2. 套餐优先（Combo-First）**
组餐永远先扫套餐：辣 → 麦辣/龙焰系列套餐；预算 ≤20 走随心配 1+1，20-30 走三件套。套餐方案和单品拼配方案都过 `calculate-price` 实时验价，**只报便宜的那个**。实测促销与"惊喜特惠"券自动叠加，报价即实付。

**3. 时段感知**
门店营业时段是真实数据。打烊前 30 分钟，它会换一家 24 小时店，并保证方案 15 分钟内取得到。

另外还有一个顺手的能力：**新品雷达**——菜单里 tags 标了「上新」的商品，一句"最近上什么新的"直接播报，不用再翻 App。

## 快速开始

### 1. 申请 Token

到 [麦当劳 MCP Server](https://github.com/M-China/mcd-mcp-server) 按指南申请 MCP Token。

### 2. 一键配置

把本仓库 `skill/` 目录放入 WorkBuddy 技能目录（`~/.workbuddy/skills/`），然后：

```bash
python skill/scripts/setup_mcp.py <你的MCP_TOKEN>
```

脚本自动把 mcd-mcp 写入 WorkBuddy MCP 配置（幂等、自动备份、不影响已有连接器）。到 WorkBuddy →【连接器】→【自定义连接器】启用（Trust）mcd-mcp。

### 3. 开聊

```
「不知道吃啥，25 块以内，看着办」
「想吃炸鸡，配点喝的」
「最近上什么新品了？」
```

确认方案后自动下单，支付二维码直接出现在对话里，扫码即付。支付走麦当劳官方通道，Skill 不接触任何资金凭证。

## 工作原理

```
query-nearby-stores ──→ storeCode + 营业时段（时段感知）
        │
        ▼
   query-meals ──→ 菜单池（套餐 / 上新 / 促销 / 麦金卡 标签）
        │
        ▼
  Combo-First 组餐引擎 ──→ 唯一方案 + 一句理由
        │
        ▼
  calculate-price ──→ 实价（含自动叠加的优惠）+ 取餐方式
        │
     用户确认
        ▼
   create-order ──→ payH5Url（15 分钟时效）
        │
        ▼
  scripts/pay_qr.py ──→ 内联 SVG 支付二维码，扫码即付
```

详细算法（预算阶梯、麦金卡精算、新品播报模板）见 [skill/references/engine-design.md](skill/references/engine-design.md)，MCP 工具集成说明见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。
