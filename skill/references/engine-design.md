# 麦上吃 · 决策引擎设计

本文档定义麦上吃的核心决策逻辑，是 `skill/SKILL.md` 提示词工程的设计依据。

## 1. 用户状态分档

| 档位 | 用户表现 | 引擎行为 |
|---|---|---|
| A · 有想法 | 表达了口味/品类/预算任一约束 | 意图匹配组餐 |
| B · 大脑空白 | "不知道吃啥""随便""看着办" | 拍板模式 |

**拍板模式铁律：最多问 2 个问题；问完必须给唯一方案。** 允许零提问直接拍板（此时用默认画像：预算 25-35、时段场景、不忌口）。

**禁止行为：一次给 3 个以上方案让用户选。** 决策瘫痪是本产品要消灭的敌人，不是要保留的风格。

## 2. 套餐优先策略（Combo-First）⭐ 核心商业逻辑

原则：**套餐单价折算永远优于单品拼配，能套不拼。**

### 2.1 组餐算法

```
输入：意图（口味/品类/忌口） + 预算 + 时段 + 门店
  ↓
Step 1  套餐扫描：从 query-meals 结果中过滤 tags 含「套餐」的商品
Step 2  意图匹配：套餐名/口味标签匹配意图（辣→麦辣/龙焰系列）
Step 3  预算阶梯过滤（见 2.2）
Step 4  缺口补齐：套餐覆盖不了的 craving（如"想吃炸鸡"但套餐是汉堡），
        用单品小加购补，优先促销价单品（discountType ≠ null）
Step 5  双向验价：calculate-price 验证套餐方案 vs 单品拼配方案，取低价
Step 6  输出：唯一方案 + 理由 + 已省金额
```

### 2.2 预算阶梯（与官方团餐搭配规则对齐，并利用在售套餐结构）

| 预算 | 策略 | 真实菜单示例（2026-10） |
|---|---|---|
| ≤20 元 | 随心配 1+1 或促销单品 | 随心配 ¥13.9-14.9、蘸酱炸鸡 ¥11.9 |
| 20-30 元 | 套餐（三件套优先）或 汉堡+饮料 | 龙焰鸡腿堡三件套 ¥26.9（原价 ¥48.5） |
| 30-40 元 | 套餐 + 小加购 | 麦辣鸡腿堡三件套 ¥33.5 + 芝士条 ¥11 |
| 40-55 元 | 四件套/双人餐 | 龙焰美味四件套 ¥29（需麦金卡） |
| 55+ 元 | 分享餐组合 | BFF四宫格小食盘双人餐 ¥62.9 |

### 2.3 麦金卡随单购检测

菜单中 `discountType = "随单购麦金卡优惠"` 的商品（如龙焰美味四件套 ¥29 vs 原价 ¥57）：

- 用户已有麦金卡 → 直接推荐，价格用优惠价
- 用户没有 → 展示差价账：`四件套优惠价 29 + 卡成本 X vs 原价 57`，让用户自己判断，**不推销**

### 2.4 学生专享

菜单含 `学生专享汉堡小食随心选`（¥27）、`学生专享饮品随心选`（¥10）。高校门店场景下优先纳入候选。

## 3. 时段感知

数据来源：门店 `businessStatus / businessStartTime / businessEndTime / reservationTimeOptions`。

- 计算当前时间距打烊的余量，余量 < 30 分钟时，方案必须满足"15 分钟内可取"
- 时段限定场景词映射：宵夜 / 早餐 / 下午茶 / 午餐 / 夜市 → 过滤对应在售品类（如宵夜时段不推咖啡）

## 4. 新品雷达

`query-meals` 返回中 tags 含「上新」的商品即新品。播报格式：

```
📱 本周上新（3 件）
1. 龙焰芝士棒鸡腿堡 ¥27 —— 浓郁奶香拉丝芝士
2. 马苏里拉拉丝芝士条 ¥11（原价 ¥16）
3. 心形薯饼 5 块 ¥15.5 —— 口口酥脆含蘸酱

想吃哪个？说一句「试试 1」直接组单。
```

新品也可以被组餐引擎引用——用户说"来点新的"时，新品优先进入套餐扫描池。

## 5. 理由生成规范

每个方案必须附带一句理由，来源优先级：

1. 时段/场景（"离打烊 16 分钟，这个 15 分钟能取"）
2. 价格锚点（"这个比单点省 13 块"）
3. 新鲜感（"本周刚上新"）
4. 口味契合（"韩式甜辣，正好你要吃辣"）

禁止空话（"这款非常受欢迎！"），理由必须引用真实数据。

## 6. 工具调用链

```
定位门店     query-nearby-stores (searchType=2, beType=1)
             / delivery-query-stores（外送场景）
拉菜单       query-meals (storeCode, orderType, beType)
新品播报     直接读 tags=上新
组餐试算     calculate-price (items[], 券可选)
下单         create-order（必须二次确认后调用）
```

已验证：2026-10-09 于真实门店全链路跑通，蘸酱炸鸡 + 茉莉奶绿雪冰 = ¥21.8（省 ¥13.1）。
